# Phase 1 — task notes

## Dependency justifications (no deps outside the pinned stack)

- `@node-rs/argon2` — the pinned argon2id password hasher (AGENTS §2). Argon2id is the
  library default; its `const enum` cannot be referenced under `verbatimModuleSyntax`,
  so the default is documented in `lib/password.ts` instead of imported.
- `shadcn` CLI (dev-time), `@base-ui/react`, `cn` — the pinned shadcn/ui stack. The CLI
  generated canonical `base-nova` primitives under `components/ui/**` (button, input,
  label, card, table, dialog); they are committed unmodified and excluded from Biome so
  formatting cannot fork them. `theme.css` maps their semantic CSS variables onto the
  §11 palette via `@theme inline`.
- `drizzle-orm` at the workspace root — dev-only, so integration tests can call the
  migrator directly. The API owns the runtime copy.

## Env change

`SEED_DEMO_CLASS` (optional class name created by `db:seed`) added to `.env.example`
and AGENTS §5 in the same change, per §15.

## Local sandbox limitations (CI is the referee)

- libSQL has no Android/Termux native binding; `@node-rs/argon2` dies with SIGILL here.
  `tests/phase1.test.ts` (role matrix, lockout, session revocation, roster) can therefore
  only run on Linux CI. Unit tests for rate limiting and the frozen contracts pass
  locally (9 assertions).
- `pnpm dlx shadcn@latest` needed two passes in this sandbox: the first stalled at the
  existing-button overwrite prompt, so the old hand-written button was moved aside and
  all six primitives were generated canonically on the second pass.
- Migration `0001_identity.sql` was generated by drizzle-kit (no hand-edited SQL).

## Verification status

`pnpm typecheck`, `pnpm lint`, and `pnpm build` pass locally. CI must run the full
`pnpm test` suite on Linux for the role matrix and real DB integration to count as green.
